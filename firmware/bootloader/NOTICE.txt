Kjern-32u4HID-C bootloader

Kjern-32u4HID-C_bootloader.hex is the Arduino Leonardo bootloader "Caterina", taken from
upstream/Caterina-Leonardo.hex (Arduino AVR Boards, bootloaders/caterina) and changed by
tools/build_bootloader.py:
  - USB vendor/product ID 1209:0002, product "Kjern Bootloader", manufacturer "Kjern"
  - the instructions that drive the Leonardo RX/TX LED pins (PB0, PD5) are replaced by NOPs
  - the factory sketch Arduino bundles in the same file is left out
The program code is otherwise byte for byte the Arduino build.

upstream/ holds the unmodified hex and, for reference, the Caterina sources it was built from.

Behaviour
  power-on with a sketch present      -> the sketch starts immediately
  no sketch in flash                  -> stays in the bootloader
  RESET button                        -> bootloader for 8 seconds, then the sketch
  serial port opened at 1200 baud and closed (what the Arduino IDE does before an upload)
                                      -> bootloader for 8 seconds, then the sketch
  The LED on PC7 fades in and out while the bootloader is active.
  The bootloader is a USB serial port speaking the AVR109 protocol (avrdude -c avr109).

Fuses: low FF, high D8, extended CB, lock 2F. Boot section 4 KB at 0x7000.
